## 🚀 Démarrage rapide

**Mode LOCAL (développement):**

```bash
cd local
./start.sh
```

**Mode DEPLOYED (réseau/serveur):**

```bash
cd deployed
export SERVER_IP=192.168.1.100
./start.sh
```
